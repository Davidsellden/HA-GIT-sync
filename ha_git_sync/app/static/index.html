DITT FILURVAL

Välj filer och mappar

Bocka i enstaka filer eller hela mappar. Ett mappval omfattar även framtida tillåtna filer. Samma urval används för push och inläsning.

Secrets, dolda kataloger, databaser, loggar, HACS och Zigbee2MQTT kan inte väljas. Mappar anges med / på slutet.

VALFRI DASHBOARD

Välj dashboard och Git-fil

Synka en dashboard som du redigerar i Home Assistants gränssnitt. Du väljer själv filnamnet i GitHub.

Välj ett eget filnamn under dashboards/. Vid push skapas filen om den saknas. Vid inläsning måste filen finnas i vald branch.

Vad synkas?

Ditt sparade filurval och eventuell vald dashboard. Filer utanför urvalet i GitHub bevaras.

Secrets, .storage, databaser, HACS-filer och Zigbee2MQTT ingår inte. Backupen omfattar Home Assistant, inklusive dess databas och interna inställningar, men inte andra tillägg.
