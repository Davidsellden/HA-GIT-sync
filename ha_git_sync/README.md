# HA Git Sync

Review, back up and sync selected Home Assistant configuration files and one UI-managed dashboard with your own private GitHub repository.

Install and update through **Home Assistant's app/add-on store**. Setup uses browser buttons: create your backup repository, enter its name, then copy the public key generated by the add-on to GitHub. No terminal or manually generated keys are needed.

- Select files/folders and preview changes before uploading or restoring.
- Export a dashboard edited in HA's UI without switching it to a file-managed dashboard.
- Create an HA backup before import and recover the last update if necessary.
- Use Swedish or English, automatically or through the panel's language selector.

Requires HA OS/Supervisor on amd64/aarch64. HACS, standalone Core and Container are not installation routes for this add-on.

Open the **Documentation** tab for the complete beginner guide, including GitHub setup, deploy keys, configuration, dashboard selection and updates.
