# HA Git Sync

Review and sync selected Home Assistant files with your own GitHub repository.

- File/folder picker with saved selections and a save-before-sync prompt.
- Separate push and import flows, with file previews and branch selection.
- HA backup, configuration validation and recovery before/after import.
- Optional sync of one UI-managed dashboard.
- Swedish and English UI, following your HA language or a manual selection.

Requires Home Assistant OS with Supervisor, amd64/aarch64, and an initialized GitHub repository. Standalone Core and Container are not supported.

[Installation, configuration and usage](DOCS.md) · [Changelog](CHANGELOG.md)

In Home Assistant, open this add-on's **Documentation** tab for the complete guide. Configure your own repository before starting; no personal HA settings or credentials are bundled.
